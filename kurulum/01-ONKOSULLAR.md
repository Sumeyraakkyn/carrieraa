# 1. Ön koşullar

Stand bilgisayarında aşağıdakiler kurulu olmalı:

- Git
- Node.js 20 veya üstü
- PostgreSQL 15 veya üstü
- Python 3.11 veya üstü

PowerShell’de sürümleri kontrol et:

```powershell
git --version
node --version
npm --version
psql --version
python --version
```

## Projeyi indir

```powershell
git clone <GITHUB_REPO_URL> carriera-main
cd carriera-main
```

`<GITHUB_REPO_URL>` yerine sana gönderilen GitHub depo adresini yaz.
