# 4. Backend API

Yeni bir PowerShell penceresi aç:

```powershell
cd carriera-main/backend
npm start
```

Başarılıysa terminalde `Sunucu http://localhost:5000 portunda calisiyor.` mesajını görürsün.

Tarayıcıdan şu adresi aç:

```text
http://localhost:5000/api/test
```

`Backend API calisiyor!` mesajı ve kullanıcı sayısı görünmelidir.

Bu terminali kapatma. Sonraki adım: [05-FRONTEND.md](05-FRONTEND.md)
